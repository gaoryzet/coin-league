📈 롱 (LONG) — 상승에 베팅
가격이 오를 것 같을 때 사용해요. 가격이 오르면 이익, 내리면 손실이에요.
예시) BTC가 지금 75,000달러인데 곧 오를 것 같다 → 롱 진입
→ 80,000달러 됐을 때 청산 → 수익 🎉
📉 숏 (SHORT) — 하락에 베팅
가격이 내릴 것 같을 때 사용해요. 가격이 내리면 이익, 오르면 손실이에요.
예시) BTC가 75,000달러인데 곧 내릴 것 같다 → 숏 진입
→ 70,000달러 됐을 때 청산 → 수익 🎉
